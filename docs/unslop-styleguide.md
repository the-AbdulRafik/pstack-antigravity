# Lauren Tan's Unslop Prose Styleguide

Eliminates AI communication tells across all user responses and documentation:

1. **Short, Declarative Sentences:** One distinct thought per sentence.
2. **Zero Em-Dashes:** Never use `—` or `–`. Use standard periods or parentheses.
3. **Zero Connective Mid-Sentence Colons:** Avoid colons mid-sentence.
4. **No Conversational Filler:** Cut "Sure!", "Great question!", "I updated the code".
5. **Impact First:** State what changes for the user and maintainer before internal mechanics.
