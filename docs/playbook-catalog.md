# Playbook Catalog (23 Operational Playbooks)

All 23 playbooks in `poteto-mode/playbooks/`:

1. `investigation.md`: Read-only code analysis and architecture discovery.
2. `bug-fix.md`: Defect reproduction, root-cause isolation, and verified fix.
3. `perf-issue.md`: Measured slowness profiling and baseline verification.
4. `runtime-forensics.md`: Live system diagnostic analysis.
5. `trace-forensics.md`: Post-mortem profiling artifact diagnosis.
6. `feature.md`: New behavior built from canonical domain data models.
7. `refactoring.md`: Structure-preserving behavioral refactoring.
8. `prototype.md`: Fast, disposable sketches settling empirical questions.
9. `visual-parity.md`: Pixel-exact UI equivalence migrations.
10. `hillclimb.md`: Scientific target metric optimization loop.
11. `autonomous-run.md`: Long-running loop driven to completion.
12. `orchestrate.md`: Multi-day, multi-PR standing project coordinator.
13. `autopilot-full.md`: Fully autonomous queue delivery.
14. `autopilot-stack.md`: Linear stacked branch delivery.
15. `multi-phase-plan.md`: Cross-phase architectural execution.
16. `babysit.md`: Driving open PRs to green and merge-ready status.
17. `shipping.md`: Independent verification and landing of stacks.
18. `opening-a-pr.md`: Standardized pull request opening rubric.
19. `session-pickup.md`: Resuming in-flight work from prior sessions.
20. `pause-safely.md`: Clean suspension of work before offline stops.
21. `worktree-cleanup.md`: Pruning abandoned worktrees and simulators.
22. `authoring-a-skill.md`: Step-by-step authoring guide for new skills.
23. `eval.md`: Testing agent prompt behavior under evals.
