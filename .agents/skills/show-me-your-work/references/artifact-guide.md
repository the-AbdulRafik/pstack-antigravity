# Antigravity Decision Trail Guide

In Google Antigravity, the `show-me-your-work` skill persists decision trails as structured markdown artifacts (`templates/decision-trail-artifact.md`) rather than ephemeral chat blocks.

## Key Sections in Decision Trails
1. **State Machine (`mermaid`):** Visualizes transitions across investigation, reproduction, execution, and audit.
2. **Decision Log Table:** One row per decision, recording the fork, choice made, evidence, and principles cited.
3. **Empirical Measurement Proof:** Baseline vs final metrics, delta analysis, and raw verification command output.
