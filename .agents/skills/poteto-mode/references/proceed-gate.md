# The Antigravity Proceed Gate Protocol

In Google Antigravity, multi-step tasks generated by `poteto-mode` must emit a plan artifact with `RequestFeedback: true`.

## How the Gate Works
1. **Plan Generation:** The coordinator writes a plan artifact using `templates/plan-artifact.md`.
2. **UI Interruption:** Antigravity intercepts the turn and renders an interactive **Proceed** button in the chat UI.
3. **Execution Authorization:** Code edits and subagent dispatching are strictly suspended until the human clicks Proceed or provides steering comments.
