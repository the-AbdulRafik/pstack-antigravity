# pstack Plugin for Google Antigravity

This directory contains the manifest and runtime configuration for the `pstack` Antigravity plugin.

## Components
* `plugin.json`: Plugin declaration and metadata for `agy plugin install`.
* `models.json`: Gemini Flash-First model tier and reasoning effort assignments.
* `hooks.json`: Lifecycle event triggers (e.g., `SessionStart`).
* `scripts/`: Hook runners supporting Node.js, PowerShell, and Bash.
