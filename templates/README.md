# Antigravity Artifact Templates

This directory contains standardized markdown templates for generating first-class **Google Antigravity Artifacts** (`write_file` with `ArtifactMetadata`).

## What Makes Antigravity Artifacts Superior to Chat Sprawl
1. **Interactive Proceed Gate (`RequestFeedback: true`):** Multi-step plans and checkpoints render a native "Proceed" button in the Antigravity UI, giving the operator an explicit gate before code edits begin.
2. **Persistence Across Compaction:** Chat messages can be compacted or scrolled away; artifacts live in the dedicated artifact directory and persist throughout the task lifecycle.
3. **Rich Visualizations:** Standard support for Mermaid state/sequence diagrams, KaTeX mathematical proofs, and styled tables.
