## Reporting a Vulnerability

We take the security of `pstack-antigravity` seriously. If you discover a security vulnerability (such as a subagent tool escalation, unconstrained workspace write, or sandbox escape):

1. **Do not create a public issue.**
2. Send an email to the project maintainers or open a **Private Vulnerability Report** via GitHub Security Advisories.
3. Include:
   * Description of the vulnerability.
   * Reproduction steps or sample prompt triggering the behavior.
   * Affected skill or subagent manifest.

We will acknowledge receipt within 48 hours and work with you to patch the vulnerability before public disclosure.
